#   FnFlow 键盘模式自动切换工具
> 专为现代 macOS 设计，随心所欲地在“媒体控制键”与“Fn 功能键 (F1–F12)”之间流畅切换。

---

很高兴能向大家介绍 **FnFlow**！这是我的第一个 macOS App 项目。

这个项目的灵感源自于我自己非常喜欢的实用小工具 **Fluor**。很可惜 Fluor 在 2021 年停止维护，虽然 2022 年推出了兼容 Apple Silicon 的 2.5.1 社区更新，但 UI 界面已显得有些陈旧，功能上也逐渐无法满足现代需求。尽管它的稳定性依然可靠，但在网络上却一直找不到类似且保持简洁有力的替代品。

因此，我决定专为新版 macOS 从头开发一套全新的 Fn 切换工具，采用全新的现代化 SwiftUI 设计与丰富功能，希望能帮到跟我有相同需求的 Mac 用户！

---

## ✨ 主要功能亮点

- 🔄 **F1–F12 模式自动切换**：根据您当前使用的最前端应用程序，自动切换键盘为“媒体键”或“标准 F1–F12 功能键”。
- 💧 **现代感液态玻璃 UI**：专为 macOS 设计的高质感菜单栏界面，具备高对比度与流畅拖动的液态玻璃切换滑块。
- 🎯 **自定义应用程序规则**：轻松为不同的 App 指定独立的键盘模式，支持搜索与快速选取正在运行的 App。
- 🔔 **多样化切换提示 (OSD)**：当应用自定义规则时，提供屏幕胶囊 OSD、菜单栏动画、系统通知横幅与提示音等 4 种提示风格（亦可完全关闭）。
- ☁️ **iCloud 同步与备份**：支持自定义规则在多台 Mac 设备间通过 iCloud 自动同步，并可随时导出/导入 JSON 配置文件。
- ⚡ **全局快捷键**：随时按下 `Option + F` 即可快速手动切换全局模式。
- 🎨 **菜单栏风格自定义**：可自由选择图标（太阳/Fn）、极简圆点或纯文本标签风格，且图标色彩会自动跟随系统强调色。
- 🚀 **开机自动启动**：支持登录时自动在后台运行。

## 🛠️ 安装说明

1. 前往 [Releases](../../releases) 页面下载最新版的 `FnFlow.dmg`。
2. 打开 DMG 并将 `FnFlow.app` 拖入 `/Applications`（应用程序）文件夹中。
3. 若打开时被 macOS Gatekeeper 拦截，请打开“终端”执行以下命令解锁：
   ```bash
   xattr -cr /Applications/FnFlow.app
   ```
