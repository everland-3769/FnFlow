#   FnFlow 鍵盤模式自動切換工具
> 專為現代 macOS 設計，隨心所欲地在「媒體控制鍵」與「Fn 功能鍵 (F1–F12)」之間流暢切換。

很高興能向大家介紹 **FnFlow**！這是我的第一個 macOS App 專案。

這個專案的靈感源自於我自己非常喜歡的實用小工具 **Fluor**。很可惜 Fluor 在 2021 年終止維護，雖然 2022 年有推出一版相容 Apple Silicon 的 2.5.1 社群更新，但 UI 介面已顯得有些陳舊，功能上也逐漸無法滿足現代需求。儘管它的穩定度依然可靠，但在網路上卻一直找不到類似且保持簡潔有力的替代品。

因此，我決定專為新版 macOS 重頭開發一套全新的 Fn 切換工具，採用全新的現代化 SwiftUI 設計與豐富功能，希望能幫到跟我有相同需求的 Mac 使用者！

---

## ✨ 主要功能亮點

- 🔄 **F1–F12 模式自動切換**：根據您當前使用的前景應用程式，自動切換鍵盤為「媒體鍵」或「標準 F1–F12 功能鍵」。
- 💧 **現代感液態玻璃 UI**：專為 macOS 設計的高質感選單列介面，具備高對比與流暢拖動的液態玻璃切換滑桿。
- 🎯 **自訂應用程式規則**：輕鬆為不同的 App 指定獨立的鍵盤模式，亦支援搜尋與快速選取執行中的 App。
- 🔔 **多樣化切換提示 (OSD)**：當套用自訂規則時，提供螢幕膠囊 OSD、選單列動畫、系統通知橫幅與提示音等 4 種提示風格（亦可完全關閉）。
- ☁️ **iCloud 同步與備份**：支援自訂規則於跨 Mac 裝置間透過 iCloud 自動同步，並可隨時匯出/匯入 JSON 設定檔。
- ⚡ **全域快捷鍵**：隨時按下 `Option + F` 即可快速手動切換全域模式。
- 🎨 **選單列風格自訂**：可自由選擇圖示（太陽/Fn）、極簡圓點或純文字標籤風格，且圖示色彩會自動跟隨系統強調色。
- 🚀 **登入時自動啟動**：支援開機登入時自動於背景執行。

## 🛠️ 安裝說明

1. 至 [Releases](../../releases) 頁面下載最新版的 `FnFlow.dmg`。
2. 開啟 DMG 並將 `FnFlow.app` 拖入 `/Applications`（應用程式）資料夾中。
3. 若開啟時被 macOS Gatekeeper 阻擋，請開啟「終端機」執行以下指令解鎖：
   ```bash
   xattr -cr /Applications/FnFlow.app
   ```
